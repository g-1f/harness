Sharing in real runs

Replays of real runs from the sharing experiment. Each node is a live Sonnet 5.5 session working through PTC code cells against a fictional sandbox, and every line, hold, cite, read and shared call shown here is taken from the run's record.

The steps and notes are written by hand from that record. The clock shows the run's own seconds. Select a node to see its stream as it actually received it: a line reaches a node at the end of its next cell, is pending until then, and never arrived if the node finished first.

How this page was made

Every run is replayed from its state.json in experiments/sharing/runs/: node states, holds, lines, artifacts, cites, reads and shared calls are the harness's own record, mapped onto hand-written steps. Within a step, events keep their real order and spacing. A line's arrival is the end of the receiving node's next cell, which is when the harness appended it to that cell's output.

The experiment, its stages and its findings are in experiments/sharing/. The design these runs exercise is v3, described on the patterns page.
